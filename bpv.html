Mijn onderzoek

Mijn BPV.

BPV betekent beroepspraktijkvorming. Tijdens BPV werk en leer je bij een leerbedrijf. Op deze pagina beantwoord ik mijn onderzoeksvragen over stage.

Wanneer is mijn BPV?

Mijn BPV is in het derde leerjaar en duurt één volledig jaar. Dit is de planning die ik van mijn opleiding heb gekregen. De exacte begin- en einddatum controleer ik bij school.

Bron: informatie over mijn BPV vanuit school.

Waar vind ik een leerbedrijf?

Ik kan zoeken naar erkende leerbedrijven via Stagemarkt. Daar kan ik bedrijven vinden die studenten begeleiden tijdens hun opleiding.

Bron: Stagemarkt.

Wat ga je doen tijdens je stage?

Tijdens mijn stage werk ik mee bij een bedrijf. Ik leer hoe een Software Developer in het echt werkt. De precieze taken hangen af van het bedrijf en de opdrachten die ik krijg.

  • Bespreken wat de opdracht is en mijn werk plannen.
  • Een ontwerp maken voor een website of programma.
  • Onderdelen van een website of programma bouwen.
  • Testen of mijn werk goed werkt.
  • Fouten verbeteren en ideeën geven om software beter te maken.
  • Samenwerken met collega's en mijn werk laten zien.

Ik heb deze informatie in mijn eigen woorden samengevat uit het kwalificatiedossier voor Software Developer van SBB.

Bron: SBB Kwalificatieregister: Software Developer.
